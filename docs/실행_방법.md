# 실행 방법

학습된 결과가 함께 들어 있어서, 받은 뒤 학습 없이 바로 실행할 수 있습니다. **Python 3.12 이상**만 있으면 됩니다.

## 1. 받기

```powershell
git clone https://github.com/leehyunjoon0902/python-study.git
```

이미 받아 두었다면 프로젝트 폴더에서 `git pull`을 실행합니다.

## 2. 시뮬레이션 화면 보기

**버튼으로:** VS Code에서 "폴더 열기"로 프로젝트 폴더를 열고, `run_viewer.py`를 연 뒤 오른쪽 위 ▶ 버튼을 누릅니다. (VS Code의 Python 확장이 필요합니다.)

**명령어로:** 프로젝트 폴더에서 실행합니다.

```powershell
python -m food_chain --watch --policy rule
```

`--policy`는 동물이 행동을 정하는 방식입니다. 환경은 세 경우 모두 같습니다.

| 값 | 뜻 | 언제 쓰나 |
|---|---|---|
| `rule` | 사람이 직접 써 넣은 규칙 | 포식자–피식자 진동을 크게 보여 줄 때 |
| `trained` | 강화학습으로 배운 행동 (기본값) | 프로젝트의 본 결과를 보여 줄 때 |
| `random` | 무작위 행동 | 비교용. 곧 멸종합니다 |

`run_viewer.py`에서는 파일 안의 `POLICY = "rule"` 한 줄을 바꾸면 됩니다.

## 3. 뷰어 조작

| 키 | 동작 |
|---|---|
| `Space` | 재생 / 정지 |
| `→` | 한 step 진행 |
| `R` | 새 배치로 다시 시작 |
| `G` | 전체 기간 개체수 그래프 창 |
| 격자 클릭 | 그 칸의 동물·지형 정보 |

- 초록은 풀(토끼 먹이), 점무늬 올리브색은 관목(사슴 먹이), 파랑은 물, 보라는 토끼 굴입니다.
- 오른쪽 그래프는 초식동물 합계(왼쪽 눈금)와 육식동물 합계(오른쪽 눈금)입니다.
- 진동 한 주기가 약 2,800 step입니다. 출렁임을 보려면 속도를 "최대"로 두고 수천 step을 돌리세요.

## 4. 그 밖의 명령

| 하고 싶은 일 | 명령 | 시간 |
|---|---|---|
| 다시 학습 | `python -m food_chain --train` | 약 6분 |
| 정책 비교 평가 | `python -m food_chain --eval` | 수 분 |
| 진동 측정 (LV 유사성) | `python -m food_chain --lv --policy rule` | 수 분 |
| 차트 다시 그리기 | `uv run python -m food_chain --plots` | 약 30초 |
| 테스트 | `python -m unittest tests.test_food_chain_core` | 약 20초 |

- **VS Code에서 버튼으로:** `Ctrl+Shift+D` → 위쪽 목록에서 항목 선택 → `F5`. 위 명령들이 목록에 들어 있습니다.
- **`config.py`의 수치를 바꿨다면** 다시 학습해야 학습된 정책에 반영됩니다. 규칙 기반 정책은 학습이 필요 없습니다.
- **학습과 평가는 기존 결과 파일을 덮어씁니다.** 발표에 쓴 결과를 남기려면 `data/` 폴더를 먼저 복사해 두세요.
- **차트만 `uv`가 필요합니다.** 그림을 그리는 패키지(matplotlib)를 쓰기 때문입니다. 이미 만들어진 그림은 `data/results/plots/` 폴더에서 바로 볼 수 있습니다.

## 5. 결과 파일

| 위치 | 내용 |
|---|---|
| `data/q_tables/` | 학습된 Q-Table 4개. `trained` 정책이 읽습니다 |
| `data/results/plots/` | 차트. 발표 핵심 그림은 `lv_timeseries_rule.png` |
| `data/results/*.csv` | 평가·측정 결과 요약. 발표 표의 수치가 들어 있습니다 |

CSV는 결과를 저장해 둔 기록입니다. 시뮬레이션이 읽는 파일이 아니라서 없어도 실행에는 문제가 없습니다. 매 step 원본 기록(큰 CSV)은 저장소에 올리지 않았고, `--eval`과 `--lv`를 실행하면 다시 만들어집니다.

## 6. 문제가 생기면

| 증상 | 해결 |
|---|---|
| `No module named food_chain` | 프로젝트 폴더에서 실행하세요 |
| Q-Table이 없다는 안내 | `python -m food_chain --train`을 먼저 실행하세요 |
| Q-Table 상태 구성이 다르다는 오류 | State 구성을 바꾼 뒤입니다. 다시 학습하세요 |
| `--plots`에서 matplotlib 오류 | `python` 대신 `uv run python`으로 실행하세요 |
| `food_chain` 안의 파일을 ▶로 실행하면 오류 | `run_viewer.py`를 실행하세요 |

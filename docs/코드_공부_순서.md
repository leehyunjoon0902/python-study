# 코드 공부 순서

`food_chain` 폴더는 약 5,250줄이지만, 발표를 위해 읽을 것은 **세 파일의 일부, 약 700줄**입니다. 전체에 2시간 반 정도 잡으면 됩니다.

## 1. 무엇을 볼지

| 파일 | 역할 | 볼 정도 |
|---|---|---|
| `config.py` | 모든 수치 | **전부** |
| `rl.py` | Q-Table, SARSA·Q-Learning, 규칙 기반 정책 | **전부** (핵심) |
| `world.py` | 환경: 관측, 한 step의 처리, 보상 | **함수 4개만** |
| `train.py` | 학습 반복, 교대 학습 | 훑어보기 |
| `simulation.py`, `analysis.py`, `__main__.py` | 평가, 진동 측정, 명령어 처리 | 역할만 |
| `viewer.py`, `plots.py` | 화면과 차트 | 읽지 않아도 됨 |

전체 흐름은 이렇습니다.

```
config(수치) → world(관측 · 행동 처리 · 보상) ⇄ rl(행동 선택 · Q 갱신) → train(반복 학습) → simulation(평가)
```

## 2. 읽는 순서

**① 뷰어를 먼저 돌려 본다 (10분).** `run_viewer.py`를 실행하고 동물을 클릭해 보세요. 코드의 변수가 화면의 무엇인지 연결됩니다.

**② `config.py` (20분).** 주석이 자세해 설계 설명서처럼 읽힙니다. 종과 먹이 관계(`PREY`, `DIET`), 시야(`VISION`), 종별 수치(`PARAMS`), 사냥 수치(`HUNT`), 보상(`REWARD_*`), 학습 설정(`ALPHA`, `GAMMA`, `EPSILON_*`)을 봅니다. "70 → 40"처럼 화살표가 있는 주석은 값을 바꾼 이유입니다.

**③ `rl.py` (40분).** 발표 질문의 대부분이 여기서 나옵니다. 위에서 아래로 읽습니다.

**④ `world.py`의 함수 4개 (40분).**

| 함수 | 볼 것 |
|---|---|
| `observe` | 동물이 무엇을 보는가. 함수 맨 위의 설명만 읽어도 됩니다 |
| `step` | 한 step의 순서: 모든 개체가 무작위 순서로 관측 → 행동 선택 → 적용 |
| `_apply` | 가장 긴 함수. `reward +=`가 나오는 줄만 찾아 보상이 언제 주어지는지 봅니다 |
| `_breed` | 번식할 때 부모가 energy를 새끼에게 떼어 줍니다 |

**⑤ `train.py` (15분).** `plan`에서 교대 학습(초식만 → 육식만 → 번갈아)을, `train`에서 반복 구조를 봅니다. 학습 모드는 번식을 끄고 죽은 개체를 바로 다시 만듭니다.

## 3. `rl.py`의 핵심

**State.** 몇 개의 작은 숫자를 묶은 것입니다. 행동은 5개(정지, 위, 아래, 왼쪽, 오른쪽)입니다.

| 종 | 성분 | State 수 |
|---|---|---|
| 토끼 | energy 3 × hydration 3 × 먹이 방향 5 × 물 방향 5 × 위험 방향 5 × 위험 거리 3 | 3,375 |
| 사슴 | 위와 같음 × 달리는 방향 5 | 16,875 |
| 여우 | energy 3 × hydration 3 × 먹이 방향 5 × 먹이 거리 3 × 물 방향 5 | 675 |
| 늑대 | 위와 같음 × 먹이 크기 3 | 2,025 |

**행동 선택 (ε-greedy).** ε의 확률로 무작위, 그 밖에는 Q값이 가장 큰 행동입니다.

```python
def select(self, state, epsilon, rng):
    if epsilon > 0.0 and rng.random() < epsilon:
        return rng.randrange(N_ACTIONS)
    return self.greedy(state, rng)
```

**두 알고리즘의 차이.** 다른 곳은 한 군데뿐입니다.

```python
# SARSA (초식): 실제로 고른 다음 행동 a2의 값
row[a] += alpha * (r + gamma * self.q[s2][a2] - row[a])

# Q-Learning (육식): 다음 상태에서 가장 큰 값
row[a] += alpha * (r + gamma * max(self.q[s2]) - row[a])
```

SARSA는 탐험하다 하는 실수까지 반영해 조심스러운 행동을 배웁니다. Q-Learning은 탐험과 무관하게 최선의 행동을 기준으로 배웁니다.

**갱신 시점 (`QPolicy.act`).** 동물이 다음 자기 차례에 새 State를 보고 행동을 고른 순간, 직전 행동을 갱신합니다. 그 사이에 받은 보상은 쌓아 둡니다. 죽으면 `died`에서 마지막 갱신을 합니다.

**Q 공유.** 종별 Q-Table 1개를 그 종의 모든 개체가 함께 씁니다.

## 4. 한 step 따라가 보기

토끼의 energy가 50, hydration이 80이고, 왼쪽에 풀이 있으며, 물가에 있고, 포식자가 보이지 않는 경우입니다.

1. **관측 (`observe`):** energy 1단계, hydration 2단계, 먹이 방향 3(왼쪽), 나머지 0 → `(1, 2, 3, 0, 0, 0)`
2. **인코딩 (`encode_herbivore`):** 여섯 숫자를 번호 하나로 합칩니다 → State 2100
3. **행동 선택 (`select`):** Q-Table 2100번 줄의 값 5개 중 가장 큰 행동
4. **직전 행동 갱신 (`update_sarsa`):** 직전 State·행동과 쌓인 보상, 지금의 State·행동으로 Q값을 고침
5. **적용 (`_apply`):** 왼쪽으로 이동 → 풀을 먹어 보상 → energy·hydration 감소 → 번식·사망 확인

여우라면 2번에서 `encode_carnivore`, 4번에서 `update_qlearning`을 쓰는 점만 다릅니다.

## 5. 발표에서 답할 수 있어야 하는 것

| 질문 | 볼 곳 |
|---|---|
| State는 무엇으로 이루어지는가 | `rl.py`의 `*_SHAPE`, `world.observe` |
| 보상은 언제 얼마나 주어지는가 | `world._apply`, `config.HUNT`, `config.REWARD_*` |
| SARSA와 Q-Learning은 어디가 다른가 | `update_sarsa`, `update_qlearning` |
| ε은 어떻게 변하는가 | `train._epsilon` |
| 학습 때와 평가 때 환경은 어떻게 다른가 | `train.train`, `World`의 `mode` |
| 교대 학습은 왜, 어떻게 하는가 | `train.plan` |
| 규칙 기반 정책과 학습된 정책의 차이는 | `RulePolicy`, `QPolicy` |
| 포식자 수가 먹이량을 따라가게 한 장치는 | `world._breed` |

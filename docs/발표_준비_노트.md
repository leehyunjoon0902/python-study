이 문서는 발표자가 "무엇을, 왜 이렇게 만들었고, 결과가 어땠는지"를 혼자 설명하고 질문에 답할 수 있도록 정리한 노트입니다.

**수치의 출처 표시**
- 규칙과 설정값은 모두 `food_chain/config.py`, `world.py`, `rl.py`, `analysis.py`에서 직접 확인했습니다.

## 1. 한 페이지 요약 (발표 첫 1분)

**무엇을 만들었나.** 50×75 격자 위에 풀밭, 관목, 물웅덩이, 토끼 굴이 있는 작은 생태계를 만들었습니다. 토끼·사슴(초식)과 여우·늑대(육식) 네 종이 살고, 각 종이 강화학습으로 살아남는 행동을 배웁니다. 초식은 SARSA, 육식은 Q-Learning을 쓰고, 같은 종의 모든 개체가 Q-Table 하나를 함께 씁니다. 토끼는 풀만, 사슴은 관목만 먹고, 여우는 토끼를, 늑대는 사슴과 토끼를 잡습니다.

**잘 된 것.**
1. **여우–토끼의 반복 진동이 나타났습니다.** 사람이 짠 규칙 기반 정책으로 16,000 step을 돌리면, 6개 seed 모두에서 토끼가 늘고 → 여우가 늘고 → 토끼가 줄고 → 여우가 주는 주기가 측정됐습니다. 평균 주기 2,809 step, 여우는 토끼보다 주기의 0.22만큼 늦게 따라갔습니다(로트카-볼테라 이론값 약 0.25). 우리는 로트카-볼테라 식을 코드에 넣지 않았습니다. 개체 하나하나의 규칙에서 진동이 저절로 생겼습니다.
2. **네 종이 4,000 step 동안 함께 살아남았습니다.** 외부 유입을 켜면 규칙 기반 6/6, 학습 정책 6/6 seed, 외부 유입을 꺼도 규칙 기반은 6/6입니다. 무작위 정책은 0/6입니다.
3. **학습 정책은 무작위보다 확실히 낫습니다.** 토끼 평균 수명이 무작위 158.2 step, 규칙 기반 169.3 step, 학습 정책 222.2 step입니다.

**안 된 것(숨기지 않고 말할 것).**
1. **학습 정책의 진동은 약합니다.** 여우–토끼 교차상관이 0.27~0.45, 진폭이 약 3배로, 규칙 기반(교차상관 평균 0.52, 토끼 진폭 8.8배)보다 훨씬 평평합니다.
2. **학습된 늑대는 외부 유입에 기대고 있습니다.** 유입을 끄면 학습 정책의 공존은 3/6 seed로 떨어지고, 멸종한 종은 모두 늑대입니다.
3. **늑대–사슴은 함께 살아남지만 로트카-볼테라형 진동은 아닙니다.** 규칙 기반에서 주기가 측정된 seed가 2/6이고, 그 둘의 지연도 이론과 맞지 않습니다.
4. 규칙 기반의 여우–토끼 진동도 "세부 기준을 모두 만족한" seed는 3/6이고, 한 seed에서는 여우가 멸종했습니다(5.4절).

## 2. 꼭 알아야 할 강화학습 기초

### 2.1 에이전트, 환경, 상태, 행동, 보상

**강화학습**은 정답을 알려 주지 않고, 행동의 결과로 받는 점수(보상)만 보고 좋은 행동 방식을 스스로 찾게 하는 학습 방법입니다. 행동하는 주체를 **에이전트**라고 하며, 여기서는 동물 한 마리 한 마리가 에이전트입니다. 에이전트가 사는 세계가 **환경**이고, 여기서는 격자 세계(`world.py`의 `World`)입니다.

**상태(state)** 는 에이전트가 행동을 고를 때 보는 정보의 요약입니다. 여기서는 "배고픔 단계, 목마름 단계, 가장 가까운 먹이·물·적의 방향" 같은 몇 개의 숫자 묶음입니다. **행동(action)** 은 정지·위·아래·왼쪽·오른쪽 5개입니다. **보상(reward)** 은 행동 직후 받는 점수로, 먹으면 +, 죽으면 −5처럼 정해 두었습니다. 에이전트는 당장의 보상이 아니라 앞으로 받을 보상의 합을 크게 만들려고 합니다.

**정책(policy)** 은 "이 상태에서는 이 행동을 한다"는 규칙 전체입니다. 강화학습의 결과물이 정책입니다. **step** 은 모든 개체가 한 번씩 행동하는 한 차례이고, **episode** 는 학습의 한 판(여기서는 400 step)입니다.

### 2.2 Q값과 Q-Table

**Q값 Q(s, a)** 는 "상태 s에서 행동 a를 하고 그 뒤로도 잘 행동했을 때 앞으로 받을 보상 합의 예상치"입니다. 모든 (상태, 행동)의 Q값을 표로 저장한 것이 **Q-Table** 입니다. 행동을 고를 때는 현재 상태의 줄에서 Q값이 가장 큰 행동을 고릅니다. 종마다 표가 하나씩 있고, 학습이 끝나면 `data/q_tables/rabbit.json`, `deer.json`, `fox.json`, `wolf.json`에 저장됩니다.

최종 학습 후 표에서 한 번이라도 갱신된 부분을 세면 다음과 같습니다(저장된 json에서 계산).

| 종 | 표 크기(상태 × 행동) | 0이 아닌 칸 | 한 번 이상 갱신된 상태 |
|---|---|---|---|
| 토끼 | 3,375 × 5 = 16,875 | 9,326 | 2,007개 (59.5%) |
| 사슴 | 16,875 × 5 = 84,375 | 22,933 | 7,865개 (46.6%) |
| 여우 | 675 × 5 = 3,375 | 1,896 | 401개 (59.4%) |
| 늑대 | 2,025 × 5 = 10,125 | 3,214 | 723개 (35.7%) |

상태의 상당 부분(늑대는 약 64%)은 학습 중 한 번도 겪지 못했습니다. 사슴은 "달리는 방향" 성분이 붙어 상태가 토끼의 5배가 되었고, 그만큼 경험이 얇게 퍼졌습니다.

### 2.3 ε-greedy (탐험과 활용)

항상 Q값이 가장 큰 행동만 고르면(**탐욕 선택**) 아직 안 해 본 더 좋은 행동을 영영 찾지 못합니다. 그래서 확률 ε(엡실론)로는 무작위 행동(**탐험**)을 하고, 나머지는 탐욕 행동(**활용**)을 합니다. 이것이 **ε-greedy** 입니다. 학습 중에는 ε을 0.3에서 0.05로 줄이고, 평가 때도 ε = 0.05를 씁니다(`config.EVAL_EPSILON`, `rl.py`의 `QTable.select`).

### 2.4 학습률 α와 할인율 γ

**학습률 α** 는 새 경험을 Q값에 얼마나 크게 반영할지 정하는 값입니다. 크면 빨리 배우지만 우연에 흔들리고, 작으면 느리지만 안정적입니다. **할인율 γ** 는 미래 보상을 지금 가치로 얼마나 쳐줄지 정합니다. γ = 0.95이면 한 step 뒤 보상 1을 지금의 0.95로 계산하므로, 에이전트가 수십 step 앞까지 내다봅니다.

### 2.5 TD 학습

**TD(시간차) 학습** 은 episode가 끝날 때까지 기다리지 않고, 매 step "실제로 받은 보상 + 다음 상태의 예상 가치"를 목표로 Q값을 조금씩 고치는 방법입니다. 목표와 현재 Q값의 차이를 **TD 오차** 라고 하고, 여기에 α를 곱한 만큼 Q값을 옮깁니다. SARSA와 Q-Learning은 모두 TD 학습이며, "다음 상태의 예상 가치"를 무엇으로 쓰는지만 다릅니다.

### 2.6 SARSA와 Q-Learning

기호: s = 현재 상태, a = 현재 행동, r = 보상, s' = 다음 상태, a' = 다음 상태에서 실제로 고른 행동.

- SARSA (토끼·사슴): `Q(s,a) ← Q(s,a) + α [ r + γ·Q(s',a') − Q(s,a) ]`
- Q-Learning (여우·늑대): `Q(s,a) ← Q(s,a) + α [ r + γ·max_b Q(s',b) − Q(s,a) ]`

SARSA는 다음에 **실제로 할 행동** a'의 Q값을 씁니다. a'가 탐험으로 뽑힌 무작위 행동이어도 그대로 씁니다. 그래서 자기 실수까지 포함한 지금 정책의 가치를 배우며, 이를 **on-policy** 라고 합니다. Q-Learning은 다음 상태에서 **가장 좋은 행동**의 Q값을 씁니다. "앞으로 최선을 다한다면"의 가치를 배우므로 **off-policy** 라고 합니다.

교과서의 cliff walking(절벽 걷기) 예제에서 Q-Learning은 절벽 옆 최단 경로를 배우고 탐험 중 가끔 떨어집니다. SARSA는 "나는 가끔 실수한다"가 가치에 반영되어 절벽에서 떨어진 안전한 길을 배웁니다. 그래서 잡히면 끝인 초식에는 SARSA를, 사냥 실패의 대가가 작은 육식에는 Q-Learning을 배정했습니다(`config.ALGORITHM`). **이 배정이 결과에 영향을 주었는지 따로 확인하는 실험은 하지 않았습니다.**

이 프로젝트의 갱신은 **지연 방식**입니다. 한 개체가 다음 자기 차례에 s'를 보고 a'를 고르는 순간, 직전 (s, a)와 그 사이 쌓인 보상 r로 갱신합니다(`rl.py`의 `QPolicy.act`). 그 사이에 잡아먹히면 −5가 더해지고, `died()`에서 미래 가치 없이 마지막 갱신(**terminal 갱신**)을 합니다. episode가 400 step에서 끝나는 것은 죽음이 아니므로 terminal로 보지 않습니다.

### 2.7 Reward shaping

**Reward shaping** 은 최종 목표(살아남기)로 가는 중간 행동에 작은 보상을 더 주어 학습을 빠르게 하는 기법입니다. 예를 들어 "포식자에게서 멀어지면 +0.05"를 주면, 토끼는 실제로 잡아먹히는 드문 경험을 기다리지 않고도 도망을 배울 수 있습니다. 잘못 설계하면 shaping 점수만 노리는 엉뚱한 행동을 배울 수 있어서, 값을 사망 벌점의 1~2% 수준(0.02~0.1)으로 작게 잡았습니다.

### 2.8 다중 에이전트와 비정상성

여러 에이전트가 같은 환경에서 함께 배우면, 토끼 입장에서는 여우의 행동이 계속 바뀌므로 같은 상태에서 같은 행동을 해도 결과가 달라집니다. 이것을 **비정상성** 이라고 합니다. SARSA와 Q-Learning의 수렴 이론은 환경이 변하지 않는다고 가정하므로, 비정상성은 학습을 흔듭니다. 그래서 한 번에 한 식성만 학습시키는 **교대 학습**을 썼습니다(3.11절).

## 3. 현재 모델의 설계

### 3.1 지형

세계는 50행 × 75열 격자입니다. 지형은 seed마다 새로 만들고, 칸의 종류는 다섯 가지입니다(`world.py`의 `World._make_terrain`).

- **물웅덩이**: 2×3 구역마다 타원 웅덩이를 하나씩 두고, 어느 칸에서든 물가까지 20칸 이내가 되게 작은 웅덩이를 보충합니다. 물 칸은 지나갈 수 없습니다. 물에 상하좌우로 붙은 땅 칸이 **물가**입니다.
- **풀밭(meadow)**: 전체의 약 45%를 목표로 타원 군집을 흩뿌립니다. **토끼의 먹이**인 풀이 여기서 자랍니다. 뜯긴 풀은 80 step에 걸쳐 다시 자라고, 절반 이상 자랐을 때만 먹을 수 있습니다.
- **관목(browse)**: 전체의 약 20%를 목표로, 풀밭·물·굴이 아닌 땅에 군집으로 둡니다. **사슴 전용 먹이**입니다. 뜯긴 관목은 120 step에 걸쳐 다시 자라(풀보다 느림) 절반 이상 자랐을 때만 먹을 수 있습니다.
- **굴(burrow)**: 땅 칸의 2.5%를 2×2 군집으로 풀밭 안에 둡니다. **토끼만** 들어갈 수 있고, 굴 안의 토끼는 포식자에게 보이지도 잡히지도 않습니다. 굴에는 풀도 물도 없어서 계속 숨어 있을 수는 없습니다.
- **맨땅**: 나머지 칸입니다.

평가 seed 1000~1005의 지형을 실제로 만들어 센 값입니다(전체 3,750칸).

| seed | 물 | 물가 | 풀밭 | 관목 | 굴 |
|---|---|---|---|---|---|
| 1000 | 351 | 176 | 1,667 | 752 | 85 |
| 1001 | 411 | 188 | 1,665 | 752 | 83 |
| 1002 | 340 | 172 | 1,625 | 756 | 85 |
| 1003 | 376 | 188 | 1,642 | 788 | 84 |
| 1004 | 385 | 200 | 1,670 | 765 | 84 |
| 1005 | 356 | 184 | 1,608 | 773 | 85 |

이전 버전에 있던 사슴용 **덤불은 없앴습니다**(6.1절).

### 3.2 개체와 자동 처리

개체마다 **energy**(0~100, 배고픔의 반대), **hydration**(0~100, 목마름의 반대), 나이, 수명이 있습니다. 한 칸에는 한 마리만 있습니다. 에이전트가 고르는 것은 이동뿐이고, 먹기·마시기·사냥·번식·사망은 환경이 자동으로 처리합니다(`World._apply`).

- **대사**: 움직이면 `move_cost`, 가만히 있으면 그 절반을 energy에서 뺍니다. 수분은 움직이든 쉬든 step마다 `thirst`만큼 줄어듭니다. 그래서 쉬어도 목마름은 그대로 진행되고, 물 없이 버티는 시간이 먹이 없이 버티는 시간보다 짧습니다.
- **마시기**: 물가에 있으면 그 step에 hydration이 30 회복됩니다.
- **먹기**: 토끼는 energy 90 미만이고 먹을 수 있는 풀 위에 있으면 자동으로 뜯습니다. 사슴은 energy 85 미만이고 관목 위에 있으면 뜯는데, 한 번에 자기 칸과 옆 칸 하나를 함께 뜯습니다. 먹이에는 수분도 조금 들어 있습니다(풀 한 칸 +8, 관목 한 칸 +5, 덜 자랐으면 비례).
- **기근 대사**: energy 35 미만이면 이동·정지 비용에 종별 배율을 곱합니다. 현재는 늑대만 0.7배이고, 여우는 1.0(절감 없음)입니다.
- **외부 유입**(평가 모드만): 여우가 2마리 미만, 늑대가 3마리 미만이면 step마다 1% 확률로 지도 가장자리에 1마리가 들어옵니다. 처음부터 0마리로 시작한 종(포식자 없음 대조)에는 적용하지 않습니다. `IMMIGRATION_ENABLED = False`나 `--no-immigration`으로 끌 수 있습니다.
- **사망**: energy ≤ 0이면 아사, hydration ≤ 0이면 탈수, 나이가 수명에 닿으면 노화, 잡히면 포식입니다. 수명은 개체마다 `max_age × U(0.8, 1.2)`입니다.

| 먹이 한 칸 energy / 수분 | 풀 16 / 8 | 관목 12 / 5 | — | — |
| 먹는 기준 / 사냥 기준 | energy < 90 | energy < 85 | energy < 40 | energy < 70 |
| 사냥 반경 | — | — | 1칸(인접) | 2칸 |
| 기근 대사(energy < 35) | 없음 | 없음 | 없음(×1.0) | 비용 × 0.7 |
| 기본 수명 max_age | 400 | 1,200 | 800 | 1,000 |
| 번식 확률(조건 충족 시 step당) | 0.02 | 0.015 | 0.03 | 0.02 |
| 번식 최소 energy / hydration | 60 / 40 | 70 / 40 | 80 / 40 | 80 / 40 |
| 번식 쿨다운(step) | 40 | 300 | 100 | 300 |
| 번식 비용(새끼 시작 energy) | 30 | 35 | 40 | 40 |
| 영역성 | 없음 | 없음 | 없음 | 번식 성사 확률 1 − n/14 |
| 외부 유입 | 없음 | 없음 | 2마리 미만, step당 1% | 3마리 미만, step당 1% |
| 방어 수단 | 굴 | 질주 | — | — |
| 개체수 상한(안전장치) | 700 | 400 | 200 | 40 |

**맨해튼 거리**는 가로 칸 수 + 세로 칸 수입니다. 시야 4는 상하좌우로 4걸음 안에 닿는 마름모 범위입니다. 포식자의 시야가 자기가 잡는 먹이 종보다 1칸 이상 넓어야 한다는 검사가 `config.py` 끝에 있습니다(여우 6 > 토끼 4, 늑대 8 > 사슴 5). 최종 평가에서 개체수 상한에 닿은 종은 없었습니다(`eval_summary.csv`의 `cap_steps_*`가 모두 0).

**이동 비용의 근거.** energy는 "몸에 비축한 양"이므로, step당 줄어드는 비율은 체중당 대사율에 해당합니다. 체중당 대사율은 체중의 −0.25제곱에 비례한다는 일반 원리(Kleiber)를 쓰면, 체중 토끼 2 / 여우 6 / 사슴 26 / 늑대 45 kg에서 상대값이 1.0 / 0.76 / 0.53 / 0.46이 됩니다. 이것을 반올림해 토끼 1.0 > 여우 0.8 > 사슴 0.6 > 늑대 0.5로 두었습니다. 큰 동물일수록 오래 버팁니다. 이전 버전의 사슴 1.3, 늑대 0.96은 이 방향과 반대였습니다(6.2절).

### 3.4 사냥 규칙 (`config.HUNT`)

사냥은 배고픈 포식자만 합니다(**포만 규칙**: 여우 energy < 40, 늑대 energy < 70). 방법은 두 가지입니다.

- **덮치기(pounce)**: 배고픈 포식자가 먹이가 있는 칸으로 들어가려 하면 확률 `pounce`로 잡고 그 칸으로 들어갑니다. 실패하면 제자리에 머뭅니다.
- **사정권 포획(catch)**: 덮치기를 하지 않은 step에, 이동한 뒤 사냥 반경 안에 먹이가 있으면 한 마리를 골라 확률로 잡습니다. 인접(1칸)이면 `catch`, 2칸이면 `catch_far`를 씁니다. 여러 마리면 잡을 확률이 가장 높은 먹이를 고릅니다.

| 포식 → 피식 | 덮치기 | 인접 포획 | 2칸 포획 | 잡았을 때 energy / hydration | 사냥 보상(× 욕구 계수) |
|---|---|---|---|---|---|
| 여우 → 토끼 | 0.24 | 0.12 | (반경 1이라 없음) | +50 / +20 | 2.0 |
| 늑대 → 토끼 | 0.1 | 0.05 | 0 | +5 / +5 | 1.0 |
| 늑대 → 사슴 | 0.4 | 0.2 | 0.1 | +45 / +30 | 3.0 |

**늑대의 2칸 사냥**은 무리 추격을 단순화한 것입니다. 사이 칸이 물이나 굴이면 2칸 거리의 먹이를 잡지 못합니다(`World.open_path`). 굴 안의 토끼는 보이지도 잡히지도 않고, 포식자와 사슴은 굴에 들어갈 수 없습니다. 여우는 사슴을 잡지 못하고, 늑대가 여우를 공격하는 관계도 없습니다.

**늑대에게 토끼는 보조 먹이입니다.** 토끼 한 마리는 +5뿐이라, 사냥 기준(energy < 70)에서 토끼를 잡아도 75를 넘지 못해 번식 문턱(80)에 닿지 않습니다. 늑대는 사슴(+45)을 먹어야만 번식합니다.

**정직하게 밝힐 점.** 늑대에게는 큰 먹이(사슴, 인접 0.2)가 작은 먹이(토끼, 0.05)보다 4배 잡기 쉽습니다. 현실과 반대입니다. 또 여우 → 토끼 인접 포획(0.12)이 늑대 → 사슴(0.2)보다 낮습니다. 이렇게 정한 이유는 6.3절과 7절에서 설명합니다.

### 3.5 사슴의 질주

사슴의 방어 수단은 숨기가 아니라 **질주**입니다. 같은 방향으로 2번 연속 이동한 뒤 또 같은 방향을 고르면, 50% 확률로 한 번에 2칸을 갑니다(`sprint_prob = 0.5`, `sprint_streak = 2`). 둘째 칸이 막혀 있으면 1칸만 갑니다. 질주로 더 간 1칸에는 energy 0.3이 더 듭니다(이동 0.6 + 0.3 = 0.9로, 따로 두 번 걷는 1.2보다 쌉니다). 방향을 바꾸거나 멈추면 연속 횟수가 0으로 돌아갑니다. 질주는 위협이 없어도 조건만 맞으면 일어납니다.

최종 평가(유입 켬, seed 평균)에서 질주 발동 횟수는 규칙 기반 9,577회(그중 위협이 보일 때 2,122회), 학습 정책 9,045회(위협이 보일 때 260회)입니다(`final_eval_imm_on.log`). 학습된 사슴은 질주를 위협 상황에서 거의 쓰지 못합니다.

### 3.6 번식 — 에너지 예산 번식

평가 모드에서만 번식합니다. 쿨다운이 끝났고 energy·hydration이 기준 이상이면 step마다 번식 확률로 옆 빈칸에 새끼를 낳습니다. 짝짓기는 없습니다(무성 번식).

번식하면 **부모가 `breed_cost`만큼 energy를 내고, 새끼는 그 energy로 시작**합니다(`ENERGY_BUDGET_BREEDING = True`). 예를 들어 여우는 energy 80 이상에서 번식할 수 있고, 번식하면 40을 내고 새끼는 energy 40으로 태어납니다. 그래서 먹이를 많이 먹어 energy가 남을 때만 잇달아 번식할 수 있고, 먹이가 줄면 번식이 저절로 멈춥니다. 새끼는 energy 40에서 시작하므로, 먹이가 부족하면 새끼부터 굶어 죽습니다. 이 규칙 덕분에 여우의 개체수 상한(영역성)을 없애도 여우 수가 토끼 수에 끌려갑니다.

늑대에게는 영역성을 남겼습니다. 늑대가 n마리일 때 번식이 `1 − n/14` 확률로만 성사됩니다(14마리면 0). 이유는 6.4절에 있습니다.

### 3.7 상태 정의

상태는 **종 이름이 아니라 역할**(초식 / 육식 / 먹이 크기를 구분하는 육식)로 정의합니다(`rl.py`의 `STATE_SHAPE`, `World.observe`). 사슴은 질주 때문에 성분이 하나 더 붙습니다.

energy와 hydration은 3단계입니다: 0~34 → 0(위험), 35~69 → 1(보통), 70~100 → 2(충분). 방향은 0 = 없음, 1 = 위, 2 = 아래, 3 = 왼쪽, 4 = 오른쪽입니다(대각선이면 세로 차이가 가로 차이 이상일 때 위/아래). 거리는 0 = 시야 안에 없음, 1 = 가까움, 2 = 멂입니다. '가까움'의 경계는 시야와 무관하게 종별로 정했습니다. 포식자는 자기 사냥 반경 기준(2칸), 초식은 "다음 step에 잡힐 수 있는 거리"(토끼 2칸, 사슴 3칸)입니다.

| 쓰는 종 | 상태 성분 (크기) | 상태 수 |
|---|---|---|
| 토끼 | energy(3) × hydration(3) × 먹이 방향(5) × 물 방향(5) × 위협 방향(5) × 위협 거리(3) | 3,375 |
| 사슴 | 토끼와 같음 × 달리는 방향(5) | 16,875 |
| 여우 | energy(3) × hydration(3) × 먹이 방향(5) × 먹이 거리(3) × 물 방향(5) | 675 |
| 늑대 | 여우와 같음 × 먹이 크기(3: 없음·소형·대형) | 2,025 |

- **먹이 방향**: 시야 안에서 먹을 수 있을 만큼 자랐고 다른 동물이 없는 가장 가까운 먹이 칸의 방향입니다. 토끼는 풀, 사슴은 관목을 찾습니다.
- **위협**: 그 초식을 잡을 수 있는 포식자(토끼는 여우·늑대, 사슴은 늑대) 가운데 시야 안에서 가장 가까운 개체입니다.
- **굴 방향(토끼만)**: 위협이 보이고, 위협이 가깝거나 굶주리지 않았으면(energy 단계 1 이상), 시야 안의 빈 굴 방향을 "먹이 방향" 자리에 넣습니다. 이미 굴 안이면 0입니다. 성분을 늘리지 않으려는 방법입니다.
- **달리는 방향(사슴만)**: 위협이 보이고 직전 step에 움직였으면 그 방향(1~4), 아니면 0입니다. 질주하려면 같은 방향을 이어 가야 하므로 그 정보를 줍니다.
- **먹이(육식)**: 시야 안에서 가장 가까운, 굴 밖의 먹이입니다. 늑대는 같은 거리에 토끼와 사슴이 함께 있으면 사슴을 봅니다.
- **물 방향**: 지형 전체에서 미리 계산한 물가까지의 최단 경로 첫걸음 방향입니다(이미 물가면 0). 첫걸음 칸이 막혀 있으면 다른 후보를 알려 줍니다. "몇 칸인가"는 상태에 없습니다.

**예시(늑대)**: (0, 2, 4, 2, 0, 2)는 "매우 배고픔, 목마르지 않음, 먹이가 오른쪽 3칸 이상, 이미 물가, 그 먹이는 대형(사슴)"입니다.

상태를 좌표가 아니라 **상대 방향과 욕구 단계**로 정의했기 때문에 지도가 바뀌어도 같은 Q-Table을 쓸 수 있습니다. 대신 "물까지 몇 칸", "포식자가 몇 마리" 같은 정보는 버렸습니다. 에이전트가 세계의 일부만 보는 이런 상황을 **부분 관측**이라고 합니다.

### 3.8 행동

0 정지, 1 위, 2 아래, 3 왼쪽, 4 오른쪽의 5개입니다. 격자 밖, 물, (들어갈 수 없는) 굴 쪽으로 움직이면 제자리에 머물고 −0.05를 받습니다. 다른 동물이 있는 칸에는 못 가지만 예외가 둘 있습니다. 배고픈 포식자가 먹이 칸으로 들어가는 것은 덮치기이고, 목마른(hydration < 35) 동물이 물가로 갈 때 그 자리에 목마르지 않은(hydration ≥ 70) 같은 식성의 동물이 있으면 자리를 바꿉니다(**자리 양보**).

### 3.9 보상 (`config.py` 보상 절)

| 사건 | 보상 | 조건 |
|---|---|---|
| 먹이 먹기 | 0.5 × 욕구 계수 | 초식(풀·관목) |
| 사냥 성공 | 여우→토끼 2.0, 늑대→토끼 1.0, 늑대→사슴 3.0 (× 욕구 계수) | 육식 |
| 물 마시기 | 0.3 × 욕구 계수 | 물가에 있는 매 step |
| 생존 | +0.01 | 살아서 step을 마칠 때마다 |
| 아사·탈수·포식 사망 | −5 | 공통 |
| 노화 사망 | 0 | 공통 |
| 막힌 이동 | −0.05 | 경계·물·들어갈 수 없는 굴 |
| 도주 shaping | +0.05 / −0.05 | 초식. 굴이 상태에 보였으면 굴 쪽으로 가거나 머물 때 +. 아니면 가까운 위협과의 거리가 늘면 +, 줄면 − |
| 추적 shaping | +0.05 / −0.02 | 육식. 배고플 때 먹이와의 거리가 줄면 +, 늘면 − |
| 물가 접근 shaping | +0.1 / −0.1 | 공통. hydration < 35일 때 물가까지 거리가 줄면 +, 늘면 − |

**욕구 계수**는 `min(1, 2 × 부족도)`, 부족도는 `(100 − 먹기 직전 값) / 100`입니다. energy 80인 토끼가 풀을 먹으면 계수 0.4로 0.2를 받고, energy 50 이하면 0.5를 그대로 받습니다. "배부를 때 먹는 것은 덜 가치 있다"는 생각으로, 욕구에 따라 보상이 달라지는 **homeostatic RL**(Keramati & Gutkin, 2014)의 아이디어를 단순화했습니다. Strannegård 2026도 에너지·수분의 함수로 보상을 줍니다 [32].

사망 −5는 다른 보상보다 훨씬 커서 "죽지 않기"가 최우선이 됩니다. 노화 사망은 행동의 잘못이 아니므로 0입니다. 물 보상이 작은 것은 물가에 있으면 매 step 자동으로 받기 때문입니다. 이 값들은 이론에서 유도한 것이 아니라 돌려 보며 정한 설계값입니다.

### 3.10 한 step의 처리 순서

살아 있는 모든 개체가 무작위 순서로 한 번씩 다음을 거칩니다(`World.step`, `World._apply`).
① 상태 관측 → ② 정책이 행동 선택(학습 중이면 여기서 직전 전이 갱신) → ③ 이동(덮치기·자리 양보·질주 포함) → ④ energy·hydration 소모(질주 추가 비용, 기근 대사 포함) → ⑤ 물가면 마시기 → ⑥ 먹기 또는 사정권 포획, shaping 계산 → ⑦ 사망 판정 → ⑧ 평가 모드면 번식. 모든 개체가 끝나면 평가 모드에서 ⑨ 외부 유입을 판정합니다.

### 3.11 학습 절차 (교대 학습)

학습은 200 episode × 400 step이고(`train.py`의 `plan`), 최종 학습에 355.2초가 걸렸습니다(`final_train.log`).

| 단계 | episode | 학습하는 종 | 상대 | ε | α |
|---|---|---|---|---|---|
| ① | 1~80 | 토끼·사슴 | 여우·늑대 = 규칙 기반 | 0.3 → 0.05 | 0.1 → 0.02 |
| ② | 81~160 | 여우·늑대 | 초식 = ①의 정책 고정(ε 0.05) | 0.3 → 0.05 | 0.1 → 0.02 |
| ③ | 161~200 | 10 episode씩 초식 ↔ 육식 | 상대는 학습 정책 고정 | 0.05 | 0.02 |

①에서 육식을 규칙 기반으로 둔 것은, 서툰 포식자를 상대로 배운 초식이 나중에 영리해진 포식자에게 무너지는 비정상성 문제를 줄이기 위해서입니다. 학습 로그에서 ε이 81번째 episode에 0.3으로 다시 뛰는 것은 단계 전환 때문입니다.

학습률에는 두 장치가 있습니다. 단계 안에서 α를 0.1에서 0.02로 줄이고, 어떤 (상태, 행동)을 n번째 갱신할 때 α = max(현재 α, 1/n)을 씁니다(`QPolicy._alpha`). 처음 몇 번은 경험의 평균을 빨리 잡고, 쌓이면 천천히 다듬는 방식입니다.

### 3.12 train 모드와 eval 모드

| 항목 | train 모드 (학습·벤치마크) | eval 모드 (평가·뷰어·LV 측정) |
|---|---|---|
| 번식 | 없음 | 있음 |
| 사망 후 | 같은 종을 무작위 위치에 즉시 재생성 | 그대로 사라짐 |
| 외부 유입 | 없음 | 있음(켜져 있을 때, 포식자만) |
| 초기 개체수 | 토끼 160, 사슴 60, 여우 30, 늑대 14 (`TRAIN_COUNT`), 학습 때는 × U(0.5, 1.5) | 토끼 120, 사슴 60, 여우 20, 늑대 6 |
| 풀·관목 재생 시간 | 기본값 × U(0.7, 1.6), 학습 때만 | 풀 80, 관목 120 |
| 처음 다 자란 칸 비율 | U(0.3, 1.0) | 0.6 |
| 초기 energy·hydration | U(30, 100) | U(60, 100) |
| ε | 일정에 따라 | 0.05 |

학습 중 번식을 끄고 재생성하는 것은, 한 종이 멸종하면 그 종이 더 이상 경험을 쌓지 못하기 때문입니다. 고정 개체수 벤치마크(4.3절)는 train 모드 규칙을 쓰되 무작위화 없이 학습 없이 400 step을 돌립니다.

## 5. 로트카-볼테라와 얼마나 비슷한가

### 5.1 로트카-볼테라(LV)란

**로트카-볼테라 모형**은 포식자와 피식자의 수가 서로 엇갈려 오르내리는 현상을 설명하는 고전 수학 모형입니다. 이야기로 풀면 이렇습니다. 먹이가 많으면 포식자가 잘 먹고 늘어납니다 → 포식자가 많으면 먹이가 줄어듭니다 → 먹이가 줄면 포식자가 굶어 줄어듭니다 → 포식자가 줄면 먹이가 다시 늘어납니다. 이 고리가 반복되며, **포식자의 정점은 먹이의 정점보다 늦게 옵니다.**

식은 간단히 다음과 같습니다(x = 먹이 수, y = 포식자 수).

- 먹이: `dx/dt = a·x − b·x·y` (스스로 늘고, 포식자를 만나는 만큼 준다)
- 포식자: `dy/dt = c·x·y − d·y` (먹이를 만나는 만큼 늘고, 스스로 죽는다)

작은 진동에서 이 모형은 **포식자가 먹이보다 주기의 약 1/4(0.25)만큼 늦게** 따라갑니다. 우리 측정 도구는 이 값을 비교 기준으로 씁니다(`analysis.py` 주석).

현실에서는 스라소니–눈덧신토끼가 약 9~10년 주기로 10배 이상 오르내리고, 스라소니가 약간 늦게 따라갑니다 [27]. 강화학습 늑대–샤무아 모델(Strannegård 2026)은 약 500 step 주기와 약 160 step(주기의 0.32)의 포식자 지연을 보였습니다 [32].

### 5.2 우리는 LV 식을 넣지 않았다

우리 코드에는 위 식이 없습니다. 각 동물은 "배고프면 먹고, 목마르면 마시고, energy가 남으면 번식하고, 0이 되면 죽는다"는 개체 규칙만 따릅니다. 그런데 여우와 토끼의 수를 시간에 따라 그려 보면 LV와 같은 모양의 반복 진동이 나타났습니다. 이렇게 개별 규칙에서 집단 패턴이 저절로 생기는 것을 **창발(emergence)** 이라고 합니다. 발표의 핵심 문장은 "LV를 흉내 낸 것이 아니라, 개체 규칙에서 LV형 진동이 나타났고, 그것이 얼마나 비슷한지 숫자로 쟀다"입니다.

### 5.3 측정 도구와 지표의 뜻

`python -m food_chain --lv --policy rule`(또는 `trained`)로 측정합니다(`analysis.py`). 기본은 seed 4개 × 8,000 step이고, 외부 유입은 끈 채로 잽니다. 최종 측정은 seed 6개 × 16,000 step으로 했습니다(`--seeds 6 --steps 16000`). 개체수를 101 step 이동 평균으로 매끄럽게 만든 뒤, 처음 1,000 step(초기 과도 구간)은 버리고 잽니다. 한 종이 0마리가 되면 그 직전까지만 분석합니다.

| 지표 | 뜻 | LV라면 |
|---|---|---|
| 주기 | 먹이 수가 한 번 오르내리는 데 걸리는 step. 먹이 수의 자기상관(자기 자신을 시간만큼 밀어 겹쳤을 때 얼마나 닮았나)이 다시 최고가 되는 시차 | 일정한 주기가 있음 |
| 포식자 지연 | 먹이 곡선을 몇 step 밀었을 때 포식자 곡선과 가장 닮는지 | 양수(포식자가 늦음) |
| 지연/주기 | 지연을 주기로 나눈 값 | 약 0.25 |
| 교차상관 | 위에서 가장 닮았을 때의 상관계수(−1~1). 클수록 포식자가 먹이를 일정하게 따라감 | 1에 가까움 |
| 진폭 | 매끄럽게 한 개체수의 최대 ÷ 최소 | 1보다 큼 |
| 주기 수 | 분석 구간 길이 ÷ 주기. 2회 미만이면 "측정 불가" | — |
| 포식 사망 비율 | 먹이 수가 줄어드는 구간에서, 먹이 사망 가운데 그 포식자에게 잡힌 비율 | LV는 먹이 감소를 포식만으로 설명 |

주기를 찾지 못했거나 2주기 미만이면 "측정 불가"로 둡니다.

### 5.5 LV와 구조적으로 다른 점

우리 모델은 LV와 같은 모양의 진동을 보이지만, 구조는 다음 점에서 다릅니다.

1. **먹이에 한계가 있습니다.** LV에서 먹이는 포식자가 없으면 끝없이 늘어납니다. 우리 토끼는 풀이 다 깎이면 굶어 죽어, 포식자가 없어도 약 470~520마리를 넘지 못합니다(4.2절).
2. **포식자가 배부르면 사냥하지 않습니다.** LV는 포식자가 먹이를 만나는 만큼 잡는다고 봅니다. 우리 여우는 energy 40 미만일 때만 사냥하고, 한 번에 한 마리만 잡습니다. 이렇게 사냥량에 상한이 있는 것을 생태학에서 **포화형 기능 반응**이라고 합니다.
3. **은신처가 있습니다.** 굴 안의 토끼는 잡히지 않아, 포식이 토끼를 0까지 밀지 못하게 막습니다.
4. **개체 단위이고 확률적입니다.** LV는 연속적인 수를 다루지만, 우리는 1마리 단위이고 번식·포획이 확률로 일어납니다. 여우가 1마리까지 떨어지면 운에 따라 멸종할 수 있습니다(seed 1004).

1번(먹이 한계)과 2번(포화형 사냥)을 LV에 더한 모형을 **Rosenzweig–MacArthur 모형**이라고 합니다. 그래서 우리 모델은 "고전 LV"보다 **Rosenzweig–MacArthur 쪽에 가깝다**고 말하는 것이 정확합니다(모형 이름은 교과서 개념이며, 이번 문서에서 별도 출처를 확인하지는 않았습니다).

## 6. 왜 이렇게 바꿨나 (실패 → 원인 → 해결)

### 6.1 덤불을 없애고 질주를 넣음

- **실패**: 이전 버전의 덤불(사슴 은신처)은 효과가 약했습니다. 덤불 안에 있던 사슴은 시간 평균 1.5~2.8마리뿐이었습니다(이전 문서의 평가 값).
- **원인**: 덤불에는 먹이가 없어 머물 이유가 적었고, 사슴이 덤불로 피하는 행동을 충분히 배우지 못했습니다.
- **해결**: 덤불을 없애고, 현실의 사슴처럼 직선에서 빨리 달리는 **질주**를 넣었습니다. 대신 늑대에게 **2칸 사냥 반경**과 더 넓은 시야(8)를 주어 균형을 맞췄습니다. 토끼 굴은 땅의 5%에서 2.5%로 줄였습니다(팀에서 정한 값입니다. 굴이 많으면 토끼가 바닥에서도 넉넉히 남아 진동이 완만해지므로, 포식의 영향이 더 크게 드러나도록 줄였습니다).

### 6.2 대사 수치를 현실 방향으로 고침

- **문제**: 이전 이동 비용은 토끼 1.0, 여우 0.8, 사슴 1.3, 늑대 0.96이었습니다. 큰 동물일수록 체중당 대사가 느리다는 현실과 반대였습니다.
- **해결**: 체중당 대사율 ∝ 체중^−0.25로 다시 계산해 토끼 1.0 > 여우 0.8 > 사슴 0.6 > 늑대 0.5로 바꿨습니다(3.3절). 갈증도 이동 비용과 같게 두어 물 없이 버티는 시간이 먹이 없이 버티는 시간보다 짧게 했고, 풀과 사냥감에서 수분을 조금 얻게 했습니다.
- **함께 바뀐 값**: 늑대가 덜 소모하게 된 만큼 사슴 한 마리의 energy를 90에서 45로 낮췄습니다(`config.py` 주석). 그대로 두면 늑대 한 마리에게 필요한 사슴 수가 반으로 줄어 균형이 깨졌다고 기록되어 있습니다.

### 6.3 구조 변경 1 — 먹이 분리(관목)

- **실패**: 사슴과 토끼가 같은 풀을 먹던 버전에서, 규칙 기반으로 16,000 step을 돌리면 6개 seed **모두에서** 여우나 토끼가 0마리가 되었고, 여우–토끼 진동은 0/6 seed에서 측정됐습니다(`core6/final_lv_rule.log`). 포식자 없음 대조에서는 토끼가 6/6 seed에서 2,032~2,857 step에 멸종했고 사슴은 평균 273마리로 불었습니다(`core6/final_eval_imm_on_seeds.log`).
- **원인**: 사슴이 한 번에 두 칸씩 풀을 뜯고 오래 살아, 풀 경쟁에서 토끼를 이겼습니다. 사슴이 불어나 토끼를 굶겨 줄이면, 토끼만 먹는 여우까지 사라졌습니다. 여우 포획 확률, 늑대 기근 대사, 사슴 번식 등 수치를 바꾼 조정 실행이 여러 번 있었지만(`core6/tune_*.log`), 이 구조를 풀지 못했습니다.
- **해결**: 사슴 전용 먹이층 **관목**(전체 칸의 20%, 재생 120 step)을 만들고, 토끼는 풀만, 사슴은 관목만 먹게 했습니다. 현실 근거는 먹이 습성의 차이입니다. 노루는 먹이의 25%가 목본, 54%가 쌍떡잎 초본이고 외떡잎(풀 포함)은 16%뿐인 선택적 섭식자이고 [7], 유럽토끼는 풀을 포함해 여러 식물을 먹는 초식동물입니다 [1]. 이렇게 먹이가 겹치지 않게 나뉘는 것을 **먹이 분할(niche partitioning)** 이라고 합니다.
- **효과**: 최종 결과에서 포식자 없음 대조의 토끼 멸종이 0/6이 되었고(4.2절), 여우–토끼 진동이 6/6 seed에서 측정됐습니다(5.4절). 단, 관목 분리와 에너지 예산 번식을 같은 단계에 함께 넣었기 때문에 **둘 중 어느 쪽이 진동에 얼마나 기여했는지는 따로 재지 않았습니다.**

### 6.4 구조 변경 2 — 에너지 예산 번식과 여우 영역성 제거

- **문제**: 이전에는 번식할 때 부모 energy를 새끼와 반씩 나눴고, 여우에게는 개체수 상한(영역성 40)이 있었습니다. 상한이 여우 수를 묶으니, 여우 수가 토끼 수를 따라 오르내리는 고리가 약했습니다(`config.py` 주석 요지).
- **해결**: 번식 때 부모가 정해진 energy(`breed_cost`)를 내고 새끼가 그만큼으로 시작하게 했습니다(3.6절). 먹은 만큼만 번식할 수 있으므로 토끼가 줄면 여우 번식이 저절로 멈춥니다. 그래서 여우의 영역성 상한을 없앴습니다. 늑대에게는 영역성을 남겼습니다. 관목 분리 뒤 사슴이 약 130마리 수준이 되었는데, 늑대 상한이 24이면 늑대가 17마리까지 불어 사슴을 30까지 누른 뒤 굶어 멸종했다고 기록되어 있어 14로 낮췄습니다(`config.py` 주석, 이 실행의 로그 파일은 확인 못 함).
- **이 변경 단독의 효과는 확인 못 함**(6.3절 끝 참고).

### 6.5 수치 조정 — 여우가 토끼를 바닥내지 않게

- **실패**: 위 두 구조를 넣은 첫 실행(여우 포획 1.0/0.5, 사냥 기준 70, 초기 8마리)에서는 seed 1000의 토끼가 약 1,000 step 만에 0마리가 되었고 여우도 함께 사라졌습니다(조정 로그 `core7/tune_a0_base_1000.log`).
- **원인**: 토끼는 여우를 떨쳐 내지 못해 추격이 잡힐 때까지 이어집니다. 그래서 step당 포획 확률은 "한 마리를 잡는 데 걸리는 시간"을 정합니다. 확률이 높으면 토끼가 드물어져도 여우가 굶지 않아 토끼를 바닥냅니다. 또 여우가 energy 70부터 사냥하면 비축분으로 오래 버티며 남은 토끼까지 잡았습니다.
- **해결**(`config.py` 주석): 여우 포획 확률 0.24/0.12, 사냥 기준 40, 기근 절감 없음(1.0), 초기 여우 20마리. 주석에 따르면 포획 0.05에서는 토끼가 320마리여도 여우가 굶어 죽었고, 0.5에서는 800 step에 토끼가 멸종했습니다. 그 사이 값 0.12를 골랐습니다.

## 7. 한계 (숨기지 않고 말할 것)

1. **학습 정책의 진동이 약합니다.** 여우–토끼 교차상관 0.27~0.45, 진폭 약 3배로, 규칙 기반(0.52, 토끼 8.8배·여우 42.6배)보다 훨씬 평평합니다. 학습된 토끼는 덜 잡히는 쪽으로 살고(굴 사용 11.2마리 대 38.2마리, 도주율 0.542 대 0.941), 학습 여우는 사냥 효율이 낮습니다. 원인을 분리하는 실험은 하지 않았습니다.
2. **학습된 늑대는 외부 유입에 의존합니다.** 유입을 끄면 학습 정책 공존이 3/6으로 떨어지고 멸종한 종은 모두 늑대입니다. 규칙 기반 늑대는 유입 없이 6/6입니다.
3. **늑대–사슴은 LV형 진동이 아닙니다.** 함께 살아남지만 주기가 측정된 seed가 규칙 기반 2/6이고, 지연도 이론과 맞지 않습니다.
4. **토끼 감소의 주원인이 포식만은 아닙니다.** 감소 구간 토끼 사망 중 여우에게 잡힌 비율은 0.38이고, 나머지는 굶주림·탈수·노화(와 늑대 포식)입니다.
5. **규칙 기반 진동은 격합니다.** 여우가 평활 기준 1마리까지 떨어지는 seed가 있고(1003, 1004), seed 1004에서는 여우가 8,827 step에 멸종했습니다. 세부 기준을 모두 만족한 seed는 3/6입니다.
6. **포획 확률이 현실과 어긋납니다.** 여우→토끼 인접 포획(0.12)이 늑대→사슴(0.2)보다 낮고, 늑대에게 토끼(0.05)가 사슴(0.2)보다 잡기 어려운 역전이 있습니다. 현실에서는 큰 먹이일수록 잡기 어렵습니다 [22]. 여우 값은 진동이 유지되는 범위에서, 늑대→토끼 값은 늑대가 토끼만 먹고 불어나지 않게 정한 것입니다.
7. **단순화가 많습니다.** 여우는 기근 내성이 없고(×1.0) 영역성도 없습니다. 현실의 여우는 세력권 동물입니다. 무성 번식이고, 짝짓기·계절·나이 구조가 없습니다. 먹이도 풀과 관목으로 완전히 나눴지만, 현실의 노루와 토끼는 먹이가 일부 겹칩니다 [1][7].
8. **위협 경험이 부족합니다.** 위협이 가까운 상황은 학습 토끼 step의 약 12.2%, 사슴의 약 3.7%뿐입니다. 표 학습은 비슷한 상태끼리 경험을 나눠 쓰지 못합니다. 늑대 상태의 약 64%, 사슴 상태의 약 53%는 한 번도 갱신되지 않았습니다. 학습 사슴은 질주를 위협 상황에서 거의 쓰지 못합니다(seed 평균 260회 대 규칙 2,122회).

10. **종별 공유 Q-Table은 개체 학습이라기보다 "종의 본능"에 가깝습니다.**
11. **SARSA/Q-Learning 배정의 효과는 검증하지 않았습니다.**

## 8. 예상 질문과 답변

**Q1. 교과서처럼 두 선이 엇갈리며 오르내리나요?**
규칙 기반 여우–토끼에서는 그렇습니다. 16,000 step 동안 6/6 seed에서 평균 2,809 step 주기의 반복 진동이 측정됐고, 여우가 토끼를 주기의 0.22만큼 늦게 따라갑니다. 다만 개체수로는 여우가 토끼보다 항상 적습니다. 영양 단계를 하나 올라갈 때 에너지는 약 10%만 전달되므로 정상입니다 [30]. 그래서 차트는 축을 나누거나(`population_*`) 각 종의 평균으로 나눠(`oscillation_*`) 비교합니다.

**Q2. 로트카-볼테라 식을 코드에 넣은 건가요?**
아닙니다. 개체마다 먹기·사냥·번식·사망 규칙만 있고, 진동은 그 결과로 나타났습니다. 우리는 그 진동이 LV와 얼마나 닮았는지를 주기, 지연, 교차상관, 진폭으로 쟀습니다(5절).

**Q3. 그럼 LV와 똑같나요?**
모양은 닮았지만 구조는 다릅니다. 풀에 한계가 있고, 여우는 배고플 때만 한 마리씩 잡고, 토끼에게 굴이 있고, 개체 단위로 확률적으로 움직입니다. 그래서 먹이 한계와 포화형 사냥을 넣은 Rosenzweig–MacArthur 모형에 더 가깝습니다. 또 토끼 감소 구간의 사망 중 여우 포식은 38%뿐이라, 먹이 감소를 포식만으로 설명하는 LV와 다릅니다.

**Q4. 지연/주기 0.22가 0.25와 가깝다는 게 무슨 뜻인가요?**
LV 모형에서는 포식자의 정점이 먹이 정점보다 주기의 약 1/4 늦게 옵니다. 우리 규칙 기반 여우는 평균 0.22만큼 늦어 이 값에 가깝습니다. seed별로는 0.13~0.28로 흩어져 있습니다. 강화학습 늑대–샤무아 모델은 0.32였습니다 [32].

**Q5. 학습 정책은 왜 진동이 약한가요?**
학습 정책의 여우–토끼는 교차상관 0.27~0.45, 진폭 약 3배입니다. 학습 토끼는 굴을 덜 쓰고 위협을 덜 마주치며, 학습 여우는 사냥 효율이 규칙 기반의 약 70%(46.7 대 66.4)입니다. 포식 압력이 약해 토끼가 크게 줄지 않으니 여우도 크게 오르내리지 않는 것으로 보입니다. 원인을 분리하는 실험은 하지 않았습니다.

**Q6. 토끼가 줄어드는 것은 여우 때문이 아니라 풀 때문 아닌가요?**
둘 다입니다. 포식자를 0마리로 두면 토끼는 120 밑으로 내려가지 않고 늘어 풀을 27~28%까지 깎고, 주로 굶어 죽습니다. 포식자가 있으면 풀이 43~46%로 남고 토끼 수가 오르내립니다. 오르내림을 만드는 것은 포식이지만, 감소 구간 사망 중 여우 포식은 38%이고 나머지 상당 부분은 굶주림·탈수입니다.

**Q7. 외부 유입은 결과를 조작한 것 아닌가요?**
그래서 켠 결과와 끈 결과를 함께 보고합니다. 유입은 여우 2마리 미만, 늑대 3마리 미만일 때만 step당 1% 확률로 1마리가 들어오는 약한 장치입니다. 규칙 기반은 유입을 꺼도 6/6이고, LV 측정은 모두 유입을 끄고 했습니다. 학습 정책은 유입을 끄면 3/6으로 떨어지므로, "학습된 늑대는 유입 없이 자립하지 못한다"고 말해야 합니다.

**Q8. 사슴은 왜 풀 대신 관목을 먹나요?**
같은 풀을 먹게 했더니 사슴이 풀 경쟁에서 이겨 토끼를 굶겨 줄였고, 토끼만 먹는 여우까지 사라졌습니다. 포식자 없음 대조에서는 토끼가 6/6 seed에서 멸종했습니다. 현실에서도 노루는 목본과 쌍떡잎 초본을 주로 먹고 풀(외떡잎)은 먹이의 16% 정도입니다 [7]. 그래서 먹이를 나눴습니다. 다만 현실에서는 먹이가 일부 겹치므로 완전히 나눈 것은 단순화입니다.

**Q9. 에너지 예산 번식이 뭔가요?**
번식할 때 부모가 정해진 energy를 내고 새끼가 그 energy로 태어나는 방식입니다. 먹은 만큼만 새끼를 낼 수 있으므로, 먹이가 줄면 번식이 저절로 멈춥니다. 그래서 여우에게 따로 개체수 상한을 두지 않아도 여우 수가 토끼 수에 끌려갑니다. NetLogo Wolf Sheep 모델(부모 energy를 새끼와 나눔)과 Strannegård 2026 모델(energy 문턱을 넘으면 번식)과 같은 계열의 규칙입니다 [31][32].

**Q10. 여우는 영역성이 없는데 늑대는 왜 있나요?**
늑대는 사슴을 오래 먹고 사냥 반경이 넓어, 상한이 없으면 사슴을 눌러 버린 뒤 굶어 멸종했습니다. 상한 24에서 늑대 17마리가 사슴을 30까지 누른 기록이 있어 14로 낮췄습니다(`config.py` 주석). 현실의 늑대도 넓은 영역을 지키고 무리에서 보통 한 쌍만 번식합니다 [15][17]. 여우도 현실에서는 세력권 동물이므로, 여우에게 영역성이 없는 것은 단순화입니다.

**Q11. 사슴의 질주는 어떻게 동작하나요?**
같은 방향으로 2번 연속 움직인 뒤 또 같은 방향을 고르면 50% 확률로 2칸을 갑니다. 추가 energy는 0.3입니다. 사슴 상태에 "달리는 방향" 성분을 넣어, 위협이 보일 때 직전에 달리던 방향을 알 수 있게 했습니다. 그 대가로 사슴 상태가 3,375에서 16,875로 5배가 되었습니다. 규칙 기반 사슴은 위협 앞에서 seed 평균 2,122번 질주했지만, 학습 사슴은 260번으로 이 능력을 잘 배우지 못했습니다.

**Q12. 늑대의 2칸 사냥은 왜 넣었나요? 물 건너편도 잡나요?**
늑대의 무리 추격을 단순화한 것입니다. 2칸 거리의 사슴을 0.1 확률로 잡을 수 있고(인접은 0.2), 토끼는 2칸에서 잡지 못합니다. 사이 칸이 물이나 굴이면 잡을 수 없습니다. 규칙 기반 늑대가 잡은 사슴 329마리 가운데 153마리가 2칸 사냥이었습니다(seed 평균). 2칸 포획을 0.2로 같게 두었을 때는 늑대가 사슴을 멸종시켰다는 기록이 있습니다(`config.py` 주석).

**Q13. 왜 늑대가 토끼를 잘 못 잡게 했나요? 큰 사슴이 더 잡기 쉬운 건 이상하지 않나요?**
이상한 것이 맞고 한계로 밝힙니다. 토끼가 사슴보다 훨씬 많아서, 늑대가 토끼를 쉽게 잡으면 토끼만으로 살아가며 "큰 먹이에 의존하는 포식자"라는 역할이 사라집니다. 그래서 늑대→토끼는 0.05, 얻는 energy도 5로 낮춰, 토끼만으로는 번식 문턱(80)에 닿지 못하게 했습니다. 그래도 마릿수로는 토끼를 더 많이 잡습니다(규칙 476 대 사슴 329).

**Q14. 여우가 토끼를 잡는 확률(0.12)이 늑대가 사슴을 잡는 확률(0.2)보다 낮은 이유는요?**
토끼는 여우를 떨쳐 내지 못해 추격이 잡힐 때까지 이어지므로, step당 확률은 "한 마리를 잡는 데 걸리는 시간"을 정합니다. 0.5에서는 토끼가 800 step 만에 멸종했고, 0.05에서는 토끼가 320마리여도 여우가 굶어 죽었습니다(`config.py` 주석). 진동이 유지되는 사이 값을 고른 것이지 현실 값을 옮긴 것은 아닙니다.

**Q15. 이동 비용은 어떻게 정했나요?**
체중당 대사율이 체중의 −0.25제곱에 비례한다는 일반 원리로, 체중 2/6/26/45 kg에서 상대값 1.0/0.76/0.53/0.46을 얻고 반올림했습니다. 큰 동물일수록 비축분으로 오래 버팁니다. 이전 값(사슴 1.3, 늑대 0.96)은 이 방향과 반대여서 고쳤습니다. 이 원리 자체의 출처는 이번 조사에서 따로 확인하지 않았습니다.

**Q16. 늑대가 멸종하는 건 굶어서인가요?**
지금 결과에서는 굶주림도 큰 원인입니다. 유입을 끄고 늑대가 멸종한 3개 seed에서 늑대 아사는 5~7마리, 노화는 4~7마리였습니다. 늑대는 수가 몇 마리뿐이라, 사슴을 몇 번 놓치거나 번식 전에 몇 마리가 죽는 것만으로도 사라질 수 있습니다. 규칙 기반 늑대는 같은 조건에서 6/6 살아남았으므로, 학습된 늑대의 사냥 실력(효율 32.7 대 44.6)도 원인으로 보입니다.

**Q17. 왜 덤불을 없앴나요?**
덤불 안에 있던 사슴이 시간 평균 1.5~2.8마리뿐이라 효과가 약했습니다. 덤불에 먹이가 없어 머물 이유가 적었고, 사슴이 그 행동을 잘 배우지 못했습니다. 그래서 숨기 대신 현실의 사슴처럼 달려서 도망치는 질주로 바꿨습니다.

**Q18. 굴은 왜 5%에서 2.5%로 줄였나요?**
사용자(팀)가 정한 값입니다. 줄인 이유를 보여 주는 실험 로그는 확인하지 못했습니다. 지금 굴은 seed마다 83~85칸이고, 규칙 기반에서 굴 안에 있던 토끼는 시간 평균 38.2마리입니다.

**Q19. 학습 정책이 규칙 기반보다 못하면 강화학습을 왜 쓰나요?**
규칙 기반은 사람이 환경 규칙을 다 알고 짠 것이고, 학습 정책은 보상만 보고 찾은 것입니다. 학습 토끼의 수명은 무작위(158.2)와 규칙 기반(169.3)보다 깁니다(222.2). 반면 도주율, 사냥 효율, 질주 사용, 늑대 자립은 규칙 기반에 못 미칩니다. 어디서 못 미치는지와 그 이유(위협 경험 부족, 상태 수 증가)를 찾아낸 것도 결과입니다.

**Q20. 학습 정책도 공존 6/6인데 학습이 더 좋은 것 아닌가요?**
유입을 켜면 둘 다 6/6이고, 유입을 끄면 규칙 6/6, 학습 3/6입니다. 학습 정책은 진동이 작아 토끼가 크게 줄지 않는 대신, 늑대가 혼자 버티지 못합니다. 공존 숫자만으로 학습이 낫다고 말할 수 없습니다.

**Q21. Q-Table이 특정 지도에 고정되지 않나요?**
상태를 좌표가 아니라 상대 방향과 욕구 단계로 정의해서, 지도나 개체수가 바뀌어도 같은 상태 정의가 적용됩니다. 학습 때 episode마다 개체수와 풀·관목 재생 속도를 무작위로 바꿨습니다. 다만 상태에 없는 정보(주변 밀도, 물까지 거리)는 구분하지 못합니다.

**Q22. 왜 신경망(DQN)을 쓰지 않았나요?**
상태가 토끼 3,375, 사슴 16,875, 여우 675, 늑대 2,025개로 표에 담을 수 있고, 표는 상태별 행동 가치를 직접 열어 볼 수 있어 해석이 쉽습니다. 다만 사슴처럼 상태가 늘면 표 학습이 약해지므로(사슴 상태의 약 53%가 미경험), 비슷한 상태끼리 경험을 나누는 신경망이 개선 후보입니다. Strannegård 2026은 PPO라는 신경망 방법을 썼습니다 [32].

**Q23. 왜 초식은 SARSA, 육식은 Q-Learning인가요?**
SARSA는 자기 실수까지 포함한 가치를 배워 위험 근처에서 보수적인 경향이 있어, 잡히면 끝인 초식에 맞다고 봤습니다. Q-Learning은 최선의 행동을 가정해 최적 가치를 직접 노리므로, 사냥 실패의 대가가 작은 육식에 맞다고 봤습니다. 이 배정의 효과를 확인하는 실험은 하지 않았습니다.

**Q24. 종이 4개인데 상태 정의가 왜 역할별인가요?**
토끼와 사슴은 둘 다 "먹이를 찾고, 물을 찾고, 자기를 잡는 포식자를 피하는" 초식이라 같은 성분을 쓰고, 사슴만 질주용 성분이 하나 더 있습니다. 여우는 먹이가 한 종류, 늑대는 크기가 다른 두 종류라 먹이 크기 성분이 더 있습니다. 표는 종마다 따로 학습하므로 같은 모양이라도 행동은 다르게 배웁니다.

**Q25. 수치는 어떻게 정했나요?**
실제 생태 자료와 선행 모델을 참고하되 "종 사이 순서는 지키고 격차는 줄인다"는 원칙을 썼습니다(`docs/수치_근거.md`). 수명은 현실처럼 사슴 > 늑대 > 여우 > 토끼이고, 이동 비용은 체중당 대사율 순서입니다. 그 뒤 seed 1~3개 짧은 실행으로 생태계가 유지되도록 조정했습니다. 포획 확률처럼 현실과 다른 값은 그 이유를 함께 밝힙니다.

**Q26. 결과가 우연이 아니라는 근거는요?**
6개 서로 다른 지도에서 세 정책을 같은 seed로 비교했습니다. 벤치마크의 학습 토끼 수명은 seed별 203.5~233.2로, 무작위(149.4~162.3)·규칙 기반(165.8~173.0)과 겹치지 않습니다. 여우–토끼 진동은 6/6 seed에서 측정됐습니다. 다만 학습 seed는 하나이고 seed 수가 적어, 3/6 같은 결과의 차이는 우연일 수 있습니다.

**Q27. 평가 때도 ε = 0.05로 무작위 행동을 하는 이유는요?**
ε = 0으로 평가하면 일부 개체가 상태가 바뀌지 않는 상황에서 '정지'만 반복하며 갇히는 일이 있었습니다(이전 문서의 구현 담당 보고). 작은 무작위성이 이 고착을 깹니다. 규칙 기반 정책은 ε을 쓰지 않습니다.

**Q28. 왜 학습 중에는 번식을 끄나요?**
학습 중 한 종이 멸종하면 그 종은 더 이상 경험을 쌓지 못합니다. 특히 늑대는 몇 마리뿐이라 쉽게 사라집니다. 그래서 학습 중에는 죽으면 바로 다시 만들고(늑대 14마리 등), 개체수 변화는 평가에서만 봅니다.

**Q29. 학습 로그에서 ε이 중간에 0.3으로 다시 올라가는 건 버그인가요?**
아닙니다. 1~80 episode는 초식만 배우고, 81 episode부터 육식이 처음 배우기 시작하므로 육식의 ε을 0.3부터 다시 줄입니다.

## 9. 실행 방법과 시연

### 9.1 실행 명령

프로젝트 폴더(`D:\26-2\강화학습`)에서 실행합니다.

| 명령 | 하는 일 |
|---|---|
| `python -m food_chain --watch` | 학습 정책으로 뷰어 실행(기본 seed 42) |
| `python -m food_chain --watch --policy rule --seed 1000` | 규칙 기반 정책, 다른 지도로 뷰어 실행(`random`도 가능) |
| `python -m food_chain --train` | 200 episode 학습(약 6분, 최종 355.2초) → `data/q_tables/*.json`, `data/results/train_log.csv` |
| `python -m food_chain --eval` | 무작위·규칙·학습 정책 비교(seed 6 × 4,000 step) + 벤치마크 + 상대 고정 비교 → `eval_*.csv` |
| `python -m food_chain --eval-ablation` | 위 평가에 포식자 없음 대조를 더함(단독으로 써도 평가 실행) |
| `python -m food_chain --eval --no-immigration --results-dir data/results/noimm` | 외부 유입을 끈 평가 |
| `python -m food_chain --lv --policy rule` | LV 측정(기본 seed 4 × 8,000 step, 유입 끔) → `lv_rule.csv`, `lv_summary.csv` |
| `python -m food_chain --lv --policy rule --seeds 6 --steps 16000` | 이 문서의 최종 LV 측정과 같은 조건 |
| `uv run --no-sync python -m food_chain --plots` | 차트 생성. 이 PC에서는 matplotlib 때문에 이 형태로 실행 |

그 밖의 옵션: `--episodes`, `--train-steps`, `--schedule joint`(동시 학습), `--train-seed`, `--seeds`, `--steps`, `--immigration`(LV를 유입 켠 채), `--results-dir`. `--watch`와 `--policy trained`는 학습된 Q-Table이 없으면 먼저 `--train`을 하라는 메시지를 냅니다.

### 9.2 뷰어

왼쪽은 격자 지도, 오른쪽 패널은 현재 turn, 종별 마릿수, 평균 배고픔·목마름, 누적 사망 원인, 최근 300 step 그래프(초식 / 육식 / 풀), 선택한 개체 정보입니다. energy나 hydration이 35 미만인 개체는 빨간 테두리로 보입니다. 관목(사슴 먹이)은 점무늬가 있는 올리브색 칸으로, 자란 정도에 따라 색이 짙어집니다. 굴은 보라색, 물은 파란색입니다. 포식자를 클릭하면 시야(노란 영역)와 사냥 반경(빨간 점선)이 함께 표시되고, 질주할 수 있는 사슴에는 진행 방향을 가리키는 작은 노란 삼각형이 붙습니다. 오른쪽 패널에는 풀·관목 비율, 굴 안 토끼 수, 사슴 질주 누적, 늑대의 2칸 사냥 누적도 나옵니다.

| 조작 | 동작 |
|---|---|
| Space | 재생 / 일시정지 |
| → | 한 step 진행 |
| R | 새 무작위 배치로 다시 시작 |
| 격자 클릭 | 동물이면 그 개체의 정보와 시야, 빈 칸이면 칸 정보 |
| 속도 버튼 | 2 / 5 / 10 / 20 / 최대 step/s |

### 9.3 시연 때 보여 줄 장면

1. **시야 비교**: 토끼(4), 사슴(5), 여우(6), 늑대(8)를 차례로 클릭해 포식자가 더 멀리 본다는 설계를 보여 줍니다.
2. **굴로 숨는 토끼**: 일시정지 후 여우 근처 토끼를 클릭하고 →키로 한 step씩 넘깁니다. `--policy rule`과 학습 정책을 비교하면 차이가 보입니다(도주율 0.941 대 0.542).
3. **진동**: `--policy rule --seed 1000`으로 최대 속도로 돌려, 토끼 증가 → 여우 증가 → 토끼 감소 → 여우 감소가 그래프에 나타나는 것을 보여 줍니다. 주기가 약 2,600 step이므로 한 바퀴를 보려면 수천 step이 필요합니다. 뷰어는 외부 유입이 켜진 상태라 LV 측정(유입 끔)과 조건이 조금 다릅니다.
4. **무작위 정책**: `--policy random`으로 사슴이 1,400~2,500 step 사이에 사라지는 것을 보여 주고 학습 정책과 대비합니다.

## 10. 용어 사전

| 용어 | 한 줄 정의 |
|---|---|
| 에이전트 | 환경 안에서 행동을 고르고 보상을 받는 주체(여기서는 동물 한 마리) |
| 상태 / 행동 / 보상 | 행동을 고를 때 보는 정보 / 고를 수 있는 선택지 / 행동 직후 받는 점수 |
| 정책 | 상태마다 어떤 행동을 할지 정한 규칙 |
| episode / step | 학습의 한 판(400 step) / 모든 개체가 한 번씩 행동하는 한 차례 |
| Q값 / Q-Table | 상태에서 행동을 한 뒤 기대되는 미래 보상 합 / 그것을 모은 표 |
| ε-greedy | 확률 ε로 무작위, 나머지는 Q값 최대 행동을 고르는 방법 |
| 학습률 α / 할인율 γ | 새 경험 반영 비율 / 미래 보상을 현재 가치로 환산하는 비율 |
| TD 학습 | 매 step "보상 + 다음 상태 가치"를 목표로 Q값을 고치는 방법 |
| SARSA / Q-Learning | 다음에 실제 할 행동의 Q값으로 / 다음 상태의 최대 Q값으로 갱신하는 방법 |
| on-policy / off-policy | 지금 행동 정책 자체를 배움 / 최적 정책을 배움 |
| terminal | 더 이상 미래가 없는 끝 상태(사망) |
| reward shaping | 학습을 돕기 위해 중간 행동에 주는 작은 보상 |
| 비정상성 | 다른 에이전트도 배우면서 환경의 반응이 바뀌는 현상 |
| 교대 학습 | 한 번에 한 식성만 배우고 상대는 고정하는 일정 |
| 부분 관측 | 에이전트가 세계의 일부만 보는 상황 |
| 규칙 기반 정책 | 사람이 if-else로 짠 비교용 정책(`RulePolicy`) |
| 대조 실험 | 한 조건(포식자)만 빼고 나머지를 같게 해 비교하는 실험 |
| seed | 무작위 결과를 재현하는 난수 시작값(지도·배치를 결정) |
| 맨해튼 거리 | 가로 칸 수 + 세로 칸 수 |
| 관목(browse) | 사슴만 먹는 먹이층. 풀보다 느리게 다시 자람 |
| 굴(burrow) | 토끼만 들어가는 은신처. 안의 토끼는 보이지도 잡히지도 않음 |
| 질주 | 사슴이 같은 방향으로 계속 달리면 50% 확률로 2칸 이동 |
| 덮치기 / 사정권 포획 | 먹이 칸으로 들어가며 잡기 / 이동 후 반경 안의 먹이를 확률로 잡기 |
| 포만 규칙 | 배고플 때만 사냥(여우 energy < 40, 늑대 < 70) |
| 기근 대사 | energy 35 미만이면 소모를 줄여 버팀(늑대 × 0.7) |
| 에너지 예산 번식 | 부모가 정해진 energy를 내고 새끼가 그 energy로 태어나는 번식 |
| 영역성 | 늑대가 많을수록 번식이 덜 성사되는 규칙(1 − n/14) |
| 외부 유입(rescue effect) | 아주 적은 종에 밖에서 개체가 들어와 멸종을 막는 현상·장치 |
| 체중당 대사율 스케일링 | 몸이 클수록 체중 1 kg당 대사가 느리다는 원리(∝ 체중^−0.25) |
| 먹이 분할 | 비슷한 종이 서로 다른 먹이를 먹어 경쟁을 피하는 것 |
| 로트카-볼테라(LV) | 포식자–피식자 수의 주기적 진동을 설명하는 고전 수학 모형 |
| Rosenzweig–MacArthur | LV에 먹이 한계와 포화형 사냥을 더한 모형 |
| 포화형 기능 반응 | 먹이가 많아져도 포식자 한 마리가 잡는 양에 상한이 있는 것 |
| 창발 | 개체 규칙에서 집단 패턴이 저절로 생기는 것 |
| 자기상관 / 교차상관 | 한 곡선을 시간만큼 밀어 자기 자신과 / 다른 곡선과 얼마나 닮았는지 |
| 주기 / 지연 / 진폭 | 한 번 오르내리는 시간 / 포식자가 늦게 따라가는 시간 / 최대 ÷ 최소 |
| 위상도 | 가로 먹이 수, 세로 포식자 수로 시간 궤적을 그린 그래프 |
| 도주율 | 위협이 가까울 때 도망치거나 굴로 간 step의 비율 |
